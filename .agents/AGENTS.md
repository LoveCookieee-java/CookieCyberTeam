### 🧬 Darwin Learned Patterns & Best Practices
- [LESSON] **SQLite In-Memory vs WAL Persistence** `[storage.sqlite]` (ROI: 0.98, SR: 100%): When designing testable SQLite engines, abstract connection retrieval via a context manager: preserve a single shared connection for `:memory:` to prevent table vaporization across calls, while enforcing `PRAGMA journal_mode=WAL` for concurrent disk databases.
- [PATTERN] **FIRST.org Exact CVSS Roundup** `[security.cvss]` (ROI: 0.97, SR: 100%): Avoid raw Python `math.ceil()` or float roundups for CVSS v3.1 scores due to IEEE-754 precision drift. Use integer modular arithmetic `int(round(val * 100000)) % 10000 == 0` to match the official FIRST specification across all boundary vectors.
- [LESSON] **Windows Process Tree Termination** `[sandbox.process]` (ROI: 0.96, SR: 100%): `proc.kill()` on Windows does not terminate spawned child processes. Use safe `subprocess.run(["taskkill", "/F", "/T", "/PID", str(proc.pid)])` to forcefully terminate the entire subtree during test runner timeouts.
- [PATTERN] **Unified AST Import Aliasing** `[sast.ast]` (ROI: 0.95, SR: 100%): Track import renaming (`import os as my_os`, `from os import system as s`) in a symbol dictionary during `visit_Import` and `visit_ImportFrom` to reliably detect disguised sinks regardless of developer aliasing.
- [LESSON] **DAG Pre-Commit Graph Validation** `[orchestration.dag]` (ROI: 0.98, SR: 100%): Always validate proposed DAG dependency mutations using a candidate in-memory graph (`graphlib.TopologicalSorter`) before committing rows to SQLite to prevent poisoning the database with circular dependency deadlocks.
- [PATTERN] **Count and Snippet-Aware SAST Regression** `[guardrails.sast]` (ROI: 0.97, SR: 100%): In Zero-Regression SAST gates, checking only the set of `(cwe_id, title)` tuples is insufficient because it permits duplicating existing vulnerabilities or adding new ones of the same type. Always track exact code snippets and compare finding counts per CWE ID (`patched_counts[cwe] > orig_counts[cwe]`).
- [PATTERN] **Syntactic AST Chunking Token Defense** `[search.ast]` (ROI: 0.98, SR: 100%): Extracting function/class AST nodes before feeding code to LLM slashes token overhead by 98% compared to naive whole-file dumping, keeping prompts well within token budgets.
- [PATTERN] **Autonomous Mailbox Loop Drainage Hook** `[orchestration.mailbox]` (ROI: 0.97, SR: 100%): To prevent multi-agent infinite ping-pong loops while enabling deep collaboration, enforce a hard Max Hop TTL (20 messages) and verify inbox drainage (`is_inbox_drained`) before closing workflows.
- [PATTERN] **Lookaround IPv4 Extraction** `[malware.ioc]` (ROI: 0.98, SR: 100%): When parsing IPv4 IOCs from mixed strings or disassembly, use `(?<![0-9])(?<![0-9]\.)` and `(?![0-9])(?!\.[0-9])` lookarounds. This captures standard addresses (including `10.0.0.1` and `127.0.0.1.` at sentence ends) while strictly rejecting 5-segment version strings like `1.2.3.4.5`.
- [LESSON] **Windows Docker Volume Mount Colons** `[sandbox.docker]` (ROI: 0.97, SR: 100%): Never pass raw Windows drive paths (`E:/path:/app:ro`) directly to Docker `-v` flags because the CLI parser splits on colons, flagging a "too many colons" error. Normalize `X:/...` to `/{x}/...` before invoking container runtimes.
- [PATTERN] **FTS5 Reserved Operator Literal Quoting** `[search.fts5]` (ROI: 0.96, SR: 100%): In SQLite FTS5 queries, always wrap user-supplied terms in double quotes (`"AND" OR "OR"`) to prevent search terms that match boolean operators from throwing `fts5: syntax error near ...` exceptions.
- [PATTERN] **AST Taint Propagation Across Subtree References** `[sast.taint]` (ROI: 0.98, SR: 100%): In AST local taint tracking, never clear taint based solely on `isinstance(value, ast.Name)` checks; inspect the entire RHS expression subtree (`any(isinstance(n, ast.Name) and n.id in tainted_vars for n in ast.walk(value))`) so that non-keyword string concatenations (`query = query + " LIMIT 1"`) or kwarg executions do not prematurely strip taint.
- [LESSON] **Mach-O 64-bit FAT vs Java Class Bytecode** `[malware.magic]` (ROI: 0.97, SR: 100%): While `0xCAFEBABE` is shared between 32-bit Mach-O FAT and Java Class files (disambiguated by Java major version 45..75), `0xCAFEBABF` (`FAT_MAGIC_64`) is exclusively 64-bit Mach-O FAT and must never fall back to Java Class bytecode.
- [PATTERN] **Diagnostic Tool Pre-Flight Input Sanitization Order** `[sandbox.tools]` (ROI: 0.96, SR: 100%): In diagnostic CLI wrappers, validate arguments against forbidden shell metacharacters and check target file existence before executing `shutil.which()`, ensuring tests and error paths remain deterministic even on hosts missing optional reverse engineering toolchains.
- [PATTERN] **Stdlib Dynamic Sandbox REST Resilience** `[sandbox.rest]` (ROI: 0.96, SR: 100%): When integrating external dynamic malware sandboxes (CAPEv2/Cuckoo), use pure-Python stdlib (`urllib.request` multipart/form-data) with injectable transport handlers. Always provide unconfigured fallback guidance with structured advisories so static triage continues uninterrupted without network dependencies.
- [PATTERN] **Multi-Version Dynamic Sandbox REST Deserialization** `[sandbox.cape]` (ROI: 0.97, SR: 100%): When interfacing with CAPEv2 and Cuckoo REST endpoints across diverse versions and enterprise forks, deserialize `task_id` dynamically across top-level keys (`task_id`, `task_ids`), nested dictionary envelopes (`data.task_ids`, `data.task_id`), raw integers (`data: int`), and nested task status dictionaries (`data.task.status`), avoiding fragile schema lock-in.
- [PATTERN] **Polyglot Syntax Dispatch & Balanced Delimiter Verification** `[guardrails.polyglot]` (ROI: 0.98, SR: 100%): In multi-language safe patch engines, never unconditionally parse patches with Python `ast.parse()`. Dispatch on file extension: use `json.loads` for `.json`, `yaml.safe_load` for `.yaml`, balanced code fences for `.md`, and pure-Python comment-aware delimiter stack checking (`()`, `[]`, `{}`) for C/JS/TS/Go/Java to safely validate non-Python patches without external toolchain requirements.
- [PATTERN] **Scaffolding vs Modification Dual-Threshold Diff Cap** `[guardrails.diff]` (ROI: 0.97, SR: 100%): Distinguish new file scaffolding (`original_code == ""`) from existing file modification. Apply a generous cap (250 lines) for new files to permit modules and test fixtures while retaining the strict Ponytail 50-line diff cap for modifications to existing code.
- [LESSON] **Token-Issuing State Persistence Across Revocations** `[guardrails.tokens]` (ROI: 0.97, SR: 100%): When enforcing capability session tokens with ephemeral active sets (`_committer_tokens`), track total tokens issued (`_tokens_issued > 0`) separately from the active token set so that revoking all active tokens maintains strict token-enforcement mode rather than mistakenly reverting to unauthenticated legacy mode.
- [PATTERN] **Case-Insensitive Windows Path Confinement** `[sandbox.path]` (ROI: 0.98, SR: 100%): On Windows or case-insensitive filesystems, never match security-sensitive directories (`.git`, `.env`) with naive string comparisons (`".git" in target.parts`). Always case-fold parts (`p.lower()`) to prevent trivial case-variation bypasses (`.GIT`, `.Git`, `.ENV`).
- [PATTERN] **Embedded Template Literal Stack Transitions** `[guardrails.polyglot]` (ROI: 0.98, SR: 100%): In polyglot delimiter validators, JS/TS template strings cannot be treated as simple dumb quote pairs. Push an embedded expression marker (`${`) onto the delimiter stack upon `${` to transition seamlessly between string literal mode and code expression mode, supporting arbitrary template nesting and object literal braces without parser divergence.
- [PATTERN] **Lexical Scope Stack Backward Compatibility** `[sast.taint]` (ROI: 0.98, SR: 100%): In AST static analyzers transitioning from global flat sets to lexical scope stacks (`scope_stack: List[Dict]`), preserve `tainted_vars` as a computed `@property` returning a union or set of all active scopes to eliminate breaking changes in legacy tests or external consumers while isolating inner functions and classes.
- [PATTERN] **Vector Prefix Whitespace Normalization** `[security.cvss]` (ROI: 0.97, SR: 100%): When parsing CVSS vectors across diverse SIEM/scanner inputs, normalize the vector prefix with regex `re.match(r"^CVSS:(?:4\.0|3\.1|3\.0)\b", upper_vec)` rather than rigid prefix slicing (`[9:]`) to tolerate arbitrary whitespace around delimiters (`CVSS:4.0 / AV : N`).
- [PATTERN] **Pathlib Division Operands Filtering** `[sast.path]` (ROI: 0.98, SR: 100%): In AST detection of dynamic file paths using operator `/` (`ast.Div`), never assume all division operations construct paths. Explicitly verify that the left or right operand is a `pathlib.Path` constructor, attribute, or path-tainted variable to prevent mathematical numeric divisions from falsely polluting the taint state.
- [PATTERN] **Scope Parameter Seed and Block-Level Hoisting** `[sast.scope]` (ROI: 0.97, SR: 100%): When initializing lexical scope stacks for functions, seed all parameter names (`args`, `kwonlyargs`, `vararg`, `kwarg`) into the local scope mapping and walk nested statements (e.g. within `if` or `try` blocks) for `global`/`nonlocal` declarations, ensuring nested scopes resolve nonlocals correctly without dropping bindings.
- [LESSON] **Host Antivirus Dynamic Signature Evasion in Test Fixtures** `[testing.soc]` (ROI: 0.98, SR: 100%): When testing detection engines with real attack strings (e.g. webshells, AMSI tampering), never write verbatim signatures directly into Python test source files because real-time host antivirus (Windows Defender) intercepts and locks the file with OSError 22. - [PATTERN] **Zero-Deletion Atomic Vault Relocation** `[containment.vault]` (ROI: 0.97, SR: 100%): In containment engines adhering to absolute file safety invariants, never call os.unlink/os.remove to quarantine suspicious files. Overwrite the source file with XOR-scrambled bytes (0x5A) to render it inert, then atomically move it to the .quarantine/ vault via os.replace, ensuring atomic relocation without destructive primitives.
- [PATTERN] **Comment-Aware Inline TOML Stripping** `[config.toml]` (ROI: 0.98, SR: 100%): In pure-Python zero-dependency TOML parsers, never strip comments using naive `# in line` checks without quote awareness, nor skip comment stripping if the value begins with a quote. Parse characters sequentially tracking active quote states and escaped characters to strip trailing comments without corrupting quoted string literals or array definitions.
- [PATTERN] **Asymmetric Vault Permission Restoration Lifecycle** `[containment.permissions]` (ROI: 0.97, SR: 100%): When enforcing zero-execution policies via `chmod 000` (`0o000`) on quarantined artifacts, restore functions must explicitly re-grant owner read permission (`stat.S_IRUSR`) prior to reading ciphertext bytes, preventing unhandled `PermissionError` when executed under non-root identities.
- [LESSON] **Subtree Process Termination and Escalation Invariants** `[sandbox.process]` (ROI: 0.97, SR: 100%): A bare `os.kill(pid, sig)` call fails to terminate spawned child processes or respect graceful-to-forceful shutdown lifecycles. Collect descendant process trees via `pgrep -P` (or `taskkill /T` on Windows) and execute a two-stage termination sequence (SIGTERM -> sleep -> SIGKILL) to eliminate zombie processes and prevent resource leaks.
- [LESSON] **Unbound Vault Context in Manifest Restoration** `[containment.manifest]` (ROI: 0.98, SR: 100%): In path-inferring restoration routines, never evaluate repository root traversals (`find_git_root(vault)`) before initializing `vault` from `quarantine_dir`, preventing `UnboundLocalError` when `workspace_root` is omitted.

- [PATTERN] **Quote-Aware Delimited Array Tokenization** `[config.toml]` (ROI: 0.98, SR: 100%): In lightweight TOML array parsers, splitting by comma without string literal tracking corrupts entries containing embedded punctuation. - [PATTERN] **Symmetric Absolute & Relative Boundary Confinement** `[guardrails.paths]` (ROI: 0.99, SR: 100%): In path-guarding engines and MCP tool handlers, never nest boundary confinement checks inside relative-path conditionals (`if not path.is_absolute()`).
